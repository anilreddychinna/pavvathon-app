PAVVATHON Functional Website Mockup

HOW TO VIEW
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. Navigate using the menu and test the free registration form.

FUNCTIONS INCLUDED
- Responsive one-page website layout
- Four pillars: Engage, Experience, Elevate, Empower
- Run, Ride and Duathlon event cards
- Registration modal with basic required-field validation
- Local browser storage for demo registrations
- Demo admin table and CSV export
- Responsive mobile layout

ADMIN DEMO
- Scroll to Registration Admin
- Password: pavvathon-demo
- The password is intentionally visible in this demo and is NOT secure.

IMPORTANT PRODUCTION LIMITATIONS
This is a front-end prototype only. Registrations stay in the browser's localStorage and are not sent to PAVVATHON.
It has no central database, secure admin authentication, email/SMS confirmations, spam protection, consent audit trail, or production privacy controls.
Do not collect real participant data with this prototype.
Before launch, connect a secure backend (for example Supabase), add server-side validation and secure admin roles, configure confirmation emails, publish privacy/consent terms, and test on the production domain.
